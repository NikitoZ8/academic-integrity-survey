# Тестирование случайного распределения респондентов

## Описание

Сайт предназначен для распределения участников социологического исследования «Соотношение студенческих практик использования ИИ и вузовских норм академической честности» между 12 вариантами анкеты, размещёнными в Яндекс Формах.

Каждый вариант содержит отдельный набор из 6 виньеток.

Распределение осуществляется случайным образом с одинаковой вероятностью выбора каждого варианта.

**Вероятность назначения одной формы:**

`1 / 12 ≈ 8,33%`

При выборке из 300 студентов ожидаемое количество назначений на одну форму составляет 25 человек. Фактические значения могут отличаться из-за случайного характера распределения.

## 1. Алгоритм распределения

В основном HTML-файле сайта используется следующий JavaScript-код:

```javascript
const deck = Math.floor(Math.random() * 12) + 1;
const url = LINKS[deck - 1];
```

- `Math.random()` — генерирует случайное число.
- `Math.floor()` — округляет результат вниз.
- `deck` — номер назначенной формы от 1 до 12.
- `LINKS[deck - 1]` — выбирает соответствующую ссылку.

Каждое назначение происходит независимо от предыдущих.

## 2. Запуск тестирования через консоль браузера

Этот способ не требует изменения файлов сайта.

1. Откройте опубликованный сайт через GitHub Pages.
2. Нажмите `F12` или `Ctrl + Shift + J`.
3. Откройте вкладку **Console**.
4. Вставьте следующий код:

```javascript
const results = Array(12).fill(0);

for (let i = 0; i < 300; i++) {
  const deck = Math.floor(Math.random() * 12) + 1;
  results[deck - 1]++;
}

console.table(
  results.map((count, index) => ({
    "Форма": index + 1,
    "Количество студентов": count
  }))
);
```

5. Нажмите `Enter`.
6. Изучите таблицу распределения.

Код моделирует 300 независимых назначений между 12 формами без переходов на Яндекс Формы.

Для повторного тестирования запустите код ещё раз.

## 3. Запуск отдельного JavaScript-файла

Если тестовый скрипт сохранён в репозитории в файле `test.js`, его можно подключить к сайту.

### Структура репозитория

```text
repository/
├── index.html
├── test.js
└── README.md
```

### Подключение

Откройте `index.html` и перед закрывающим тегом `</body>` добавьте:

```html
<script src="./test.js"></script>
```

Сохраните изменения через GitHub, дождитесь обновления GitHub Pages и откройте сайт.

Затем:

1. Нажмите `F12`.
2. Перейдите во вкладку **Console**.
3. Обновите страницу.
4. Посмотрите таблицу результатов тестирования.

Скрипт выполнится автоматически при загрузке страницы.

**Важно:** после завершения тестирования удалите строку подключения `test.js` из `index.html`, чтобы тестовый код не запускался у участников исследования.

## 4. Интерпретация результатов

При 300 назначениях ожидается в среднем 25 человек на каждую форму.

Однако алгоритм не обеспечивает строго одинаковую численность групп.

Например:

| Форма | Назначений |
|---|---:|
| 1 | 24 |
| 2 | 28 |
| 3 | 22 |
| 4 | 26 |
| 5 | 27 |
| 6 | 23 |
| 7 | 25 |
| 8 | 21 |
| 9 | 29 |
| 10 | 24 |
| 11 | 26 |
| 12 | 25 |
| **Итого** | **300** |

Таблица иллюстративная. При каждом запуске результаты будут различаться.

Неравномерность численности групп сама по себе не означает ошибку алгоритма.

## 5. Проверка реальных переходов

Помимо моделирования необходимо проверить работу сайта:

1. Убедитесь, что все 12 ссылок в массиве `LINKS` заменены на действующие адреса Яндекс Форм.
2. Откройте главную страницу сайта.
3. Нажмите «Пройти опрос».
4. Проверьте, что открылась одна из 12 анкет.
5. Вернитесь на главную страницу и обновите её.
6. Повторите проверку несколько раз.

При необходимости проверить конкретную форму можно временно вывести её номер в консоль основного скрипта:

```javascript
console.log("Назначена форма:", deck);
```

Эту строку нужно разместить после вычисления переменной `deck`.

## 6. Ограничения

- Алгоритм не гарантирует ровно 25 назначений на каждую форму.
- Повторное посещение сайта может привести к назначению другой формы.
- Тестирование 300 назначений не создаёт реальные ответы в Яндекс Формах.
- Назначение формы не гарантирует её заполнение респондентом.
- Численность завершённых анкет необходимо проверять отдельно после сбора данных.

## 7. Методологическое описание

Для включения в описание методики исследования:

«Распределение респондентов между 12 экспериментальными наборами виньеток осуществлялось посредством независимой равновероятной рандомизации, реализованной на JavaScript с использованием функции Math.random(). Вероятность назначения каждого набора составляла 1/12. Рандомизация не предполагала принудительного выравнивания численности экспериментальных групп».

---

**Назначение тестирования:** проверка корректности алгоритма случайного назначения экспериментальных наборов и работоспособности переходов к анкетам.
